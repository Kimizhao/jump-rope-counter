# Jump Rope Counter

AI-powered jump rope counter built with React, Vite, and MediaPipe.

## Development

```bash
npm ci
npm run dev
```

## Production Build

```bash
npm run build
```

## GitHub Pages

This repository is configured to deploy automatically to GitHub Pages through GitHub Actions when changes are merged into `main`.

- Expected site URL: https://kimizhao.github.io/jump-rope-counter/
- Workflow file: `.github/workflows/deploy-pages.yml`

If the Pages site has not been enabled before, GitHub may take a short time to publish the first deployment after the workflow runs.
